## 交付行为

为单份与多份报告交付筛选、折叠、窄屏和打印体验，并在大量问题或生成异常时完整交付或明确失败，支持凭已有材料有界重试。

## 验收条件

- [ ] 覆盖大量问题、多仓库、长证据文本和长中文说明；不得通过截断问题集合通过校验，超出能力或预算时明确报错。
- [ ] 对模型超时、返回截断 HTML、漏问题、改等级、错误统计及无效输出执行有次数或预算上限的修复；无法修复时保留诊断，不发布成功文件。
- [ ] 分别记录材料与 HTML 阶段的模型用量及耗时；重试只使用已有材料，不重新审查、不重新收集代码或知识。
- [ ] 实现按仓库或审查单元、等级和类别筛选，以及问题详情折叠；完善键盘操作、窄屏和打印布局，合理使用留白、层次与图表，信息不只依赖颜色。使用单份及多份、短报告及长报告在浏览器验收，证据文本保持安全，修复过程不能引入外部资源或敏感路径。
- [ ] 使用可控模型从 CLI 重现失败与恢复，并以真实模型生成的代表性报告完成视觉验收；确认现有成品不被覆盖，相同输入的事实一致而不强求排版逐字相同。
