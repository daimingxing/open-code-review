## 验收条件

- [x] 保留 `write_html` 完整创建或替换草稿；新增独立 `edit_html`，以唯一原文片段执行精确替换。无草稿、原文为空、未匹配或匹配不唯一时，反馈原因且原稿不变；允许用空替换文本删除内容。模型可在同一循环修正调用。
- [x] 草稿可按需局部读取，返回可定位范围及截断信息；共享上下文压缩后仍能重新读取并编辑。存储形式与读取接口优先复用既有能力，不把落盘或新增专用读取工具作为强制架构。
- [x] 提示词和工具说明明确完整写入与局部编辑职责。可控模型端到端完成“创建草稿 → 局部读取 → 编辑 → 明确结束 → 发布”，无需为局部修订第二次输出完整 HTML；最终文件精确对应成功修订后的草稿，未改部分保留。
- [x] 写入、编辑和读取仅针对本次运行草稿；不提前写入最终目标，不修改报告 JSON。循环未完成、取消、发布失败及已有目标文件的行为保持正确，失败操作和清理不破坏已有有效成果。
- [x] 零工具调用的日志不再混同解析或执行失败；草稿反馈说明尚未发布，完成事件和最终保存事件可区分。文字总结不自动完成任务，不因本次提示优化新增重试循环；共享输出路由及机器可读结果不被污染。
- [x] 历史审查耗时明确标识，多份材料求和说明口径；本次 HTML 生成耗时单独表示。累计输入输出保持原含义，缓存用量在实际可用时展示，缺失及部分缺失 usage 如实标记，不误称当前上下文、唯一材料大小或服务商计费。
- [x] MCP 工具定义及参数说明沿用动态发现；OCR 对不存在的工具或违反服务明确参数规则的请求返回可纠正工具结果。错误请求不被发给服务，模型修正后继续原循环；反馈使用本次开放的工具及规则，不暴露凭据、未授权工具或无必要的请求正文。
- [x] 参数规则严格按 MCP 声明解释：覆盖必填、类型等确定错误；明确禁止额外属性时可拒绝，合法开放字段必须保留。不得仅用 `properties` 列表拒绝一切额外参数，不改写第三方声明或静默删参。不增加 report 专用或某个文件服务专用的参数猜测逻辑。
- [x] 本地调用校验与真正的 MCP 调用分别记录，不伪造知识读取成功或 MCP 服务故障。服务执行错误及目录越界拒绝继续生效；不扩大授权根，不为消除失败数放开源码、环境文件。
- [x] 自动化覆盖完整写入后局部修订、失败不改稿、压缩后再编辑、仅文字后补结束调用、累计/缓存/缺失用量，以及 MCP 错误调用纠正、开放额外字段、未调用服务与越界拒绝。以 CLI、工具响应、服务调用记录和最终文件观察行为，不要求固定模型措辞、DOM 或全局调用次数。
- [x] 更新必要用户说明和可复跑的开发复测入口，运行适用测试与检查，记录命令、结果和环境限制。真实模型效果验证与可控模型测试分开记录；确认可局部编辑不等于保证每次模型都选择编辑或保证固定成本降幅。

## 实施边界

- 复用共享智能体循环、上下文容量、压缩阈值、压缩任务和预算；本次不重构它们，不因累计 token 较大而降低 report 专属阈值。
- 优先复用现有工具分发、错误反馈、参数校验和用量字段，补齐缺口；不先建立通用插件框架、草稿恢复系统或新的知识检索系统。
- 参数或编辑操作的有效性检查不等于 HTML 内容审查。保持样式、标签、脚本及事实不做程序验收，不固定页面结构，不因展示差异拒绝产物。
- 不修改本机第三方 MCP 包，不自研或替换知识 MCP，不新增行区间读取能力。声明允许额外字段时，未被服务使用的参数未必能由 OCR 判错；如实记录此限制，不保证本轮消除所有全文退化。
- 窄屏样式迭代、知识应用正确性逐项评估、收费核算，以及知识观测体系的全面重设计不纳入本工单。
- 作为一张已确认工单实施，内部按可验证增量推进：先跑通局部编辑与发布，再完善运行信息和 MCP 纠正反馈，最后整体回归；每个行为自带测试，不另设仅做测试或文档的工单。
