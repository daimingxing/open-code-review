# 以独立报告材料分离审查与报告生成

状态：已接受；日期：2026-09-30。

前端、后端等仓库需要分别审查，再组合报告；在一次审查结束时直接生成最终 HTML 会绑定单仓库范围，也使更换样式需要重审。决定由审查按需生成独立、版本化的报告 JSON，再由报告命令消费一份或多份材料；原生 OCR 输出保持原语义，不兼作或合并为该材料。报告阶段不读取代码、Git、知识库或会话补充事实，因此所有必要证据和限制必须在审查及材料阶段保存，这会增加材料契约的完整性要求，但允许独立重生成报告。

需求与行为见 [Spec](../../.scratch/review-report/spec.md#解决方案)；实施与验收跟踪见[工单索引](../../.scratch/review-report/README.md)。
