# 通过原生工具按需读取显式授权的知识目录

状态：已接受；更新日期：2026-11-03。替代 2026-09-30 的文件 MCP 专用知识接入选择。

知识资料独立于业务 Git 历史维护，全文注入又会增加上下文消耗。决定通过 `review --knowledge-dir` 显式授权一个只读目录，复用原生读取、查找和搜索工具按需查阅；目录及用途进入任务知识区块，系统提示词只说明通用职责。背景提供索引与阅读指引，不承担授权。知识读取磁盘内容，代码仍读取被审查版本；仓库内知识资料从代码审查目标及覆盖中排除。

原文件 MCP 与原生工具能力重复，且服务不支持任意按行读取，模型误传参数时可能意外读取全文。统一工具减少能力和参数差异，代价是原生工具需要明确区分目录授权、磁盘知识和 Git 源码。通用 MCP 继续保留，用户显式配置的其他服务不受影响。访问事实进入会话和报告材料，恢复校验检查知识配置及已读取资料；工具读取成功仍不能证明知识正确应用。本阶段使用 low effort 验证功能，不作审查质量承诺。

需求、工单及验收见[原生知识库 Spec](../../.scratch/native-knowledge/spec.md)、[01 原生知识审查](../../.scratch/native-knowledge/issues/01-native-knowledge-review.md)、[02 报告材料与功能验收](../../.scratch/native-knowledge/issues/02-knowledge-report-material.md)及[复测记录](../retests/knowledge-access/README.md)。旧审查与报告 Spec 保留为历史规格，不继续维护文件 MCP 方案。
