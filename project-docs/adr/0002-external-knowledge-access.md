# 由原生规则关联外部知识，通过现成 MCP 按需读取

状态：历史决策，正在迁移；原接受日期：2026-09-30。

2026-11-03：文件 MCP 专用知识采集已清理，通用 MCP 保留。后续由[原生知识库 Spec](../../.scratch/native-knowledge/spec.md)中的显式目录参数授权原生工具查阅；新入口尚未实现。下文保留原决定及理由。

知识不能依赖业务 Git 历史中存在对应文件，大型知识全文注入又会占用审查上下文。决定由原生规则正文声明独立知识库的索引与查阅要求，复用 OCR 的 MCP 接入和现成文件服务按需读取；规则决定使用哪些资料，服务根目录和只读工具白名单决定访问权限，二者不混为一体。小型知识保留 Markdown 规则直接注入的后备方式，首版不新增规则协议、自研检索服务或内置读取工具，以便后续 UI 管理同一套外部资料；代价是需要配置外部服务并验证模型实际应用效果，不能将工具读取成功视为审查正确。

需求与边界见 [Spec](../../.scratch/review-report/spec.md#职责与扩展边界)；能力证据见[规则与知识读取](../open-code-review/rules-and-context.md)，实施与验收跟踪见[工单索引](../../.scratch/review-report/README.md)。
