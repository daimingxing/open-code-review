# 允许模型生成 HTML，事实仍由报告材料约束

状态：已接受；日期：2026-09-30。

报告需要适应不同材料规模和视觉需求，完全固定的模板填充会将材料与页面结构过度绑定。决定由命名模板提供内容、视觉和交互要求，允许模型基于报告 JSON 组织表达并生成完整 HTML；程序计算和核验统计、问题集合及输出要求，模型不得补充来源外的事实、改变等级或再次审查。相较固定渲染，此方案保留排版灵活性，但增加模型成本和校验负担；生成与修复必须有界，校验失败不得发布成功成品，自动校验也不被视为模型事实正确的充分保证。

内容与交付要求见 [Spec](../../.scratch/review-report/spec.md#模型生成-html)；实施与验收跟踪见[工单索引](../../.scratch/review-report/README.md)。
