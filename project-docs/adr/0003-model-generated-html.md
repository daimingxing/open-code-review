# 由智能体循环生成 HTML，检查规则后置

状态：已接受；更新日期：2026-10-16。替代原先由固定单轮请求生成、经脚本校验后发布的实现选择。

报告的视觉样式尚未定型，严格校验会在产物尚不可评估时阻断生成。首轮决定复用 review 的智能体循环、上下文容量和压缩机制，由提示词引导模型优先使用报告 JSON 与 HTML 模板/样式资源，并通过查找、读取、搜索及 HTML 写入工具完成报告。提示词建议避免重复读取源码或重新审查，但不增加 report 专用路径权限控制；模型可按判断使用循环已有的读取能力。缺少事实时优先补充 review 阶段的报告 JSON。首轮不解析、限制或校验 HTML 内容，先根据真实生成效果迭代，再决定是否加入稳定、基础的检查规则。

此选择先建立可运行的生成与迭代路径，代价是首轮 HTML 的结构、事实完整性和浏览器安全均不由脚本保证，提示词也不能强制模型遵循素材优先的建议。模型上下文和压缩沿用已有机制；文件保存仍遵循路径校验、防覆盖和原子写入。后续 HTML 检查应只覆盖从真实产物中确认的稳定需求，不能把标签、样式或布局偏差当作失败。

内容与首轮交付要求见 [Spec](../../.scratch/review-report/spec.md#智能体生成-html)；实施与验收跟踪见[工单索引](../../.scratch/review-report/README.md)。
