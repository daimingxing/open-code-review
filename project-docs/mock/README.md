# 人工验收材料

本目录是面向用户的产品验收入口，保存可直接运行的验证脚本、稳定测试输入和简明步骤。材料应帮助使用者构建本地程序、运行场景并判断实际结果；开发过程日志、历史审查证据和复杂排障记录放在 [`project-docs/retests/`](../retests/README.md)。

开发者的回归命令和历史结果已归入 [`project-docs/retests/`](../retests/README.md)。当前可亲自体验的场景是[报告 HTML](report/README.md)：使用本地构建的二次开发 CLI 和真实模型，将报告材料 JSON 生成为 HTML。每个场景应提供可直接运行的入口、所需输入、准备方式和预期结果；尚未提供稳定样例输入的场景须明确说明。
