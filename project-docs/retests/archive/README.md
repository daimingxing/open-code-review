# 审查与报告验收档案

本档案保存 2026-10 的实施验收记录、失败尝试、真实服务证据和环境限制。它是历史证据来源，不是当前命令入口；可重跑步骤已提炼到 [`report-material`](../report-material/README.md)、[`html-report`](../html-report/README.md) 和 [`knowledge-access`](../knowledge-access/README.md)。历史命令可能引用当时的工作树和旧文件位置，应以场景目录中的当前步骤为准。

旧文件名中的 `external-knowledge-01-` 是当时第一张工单的编号前缀，不是需要长期保留的场景编号；相关脚本、配置和记录现按知识访问场景归档或改用职责名称。

本次功能的 Spec、工单和完成验收入口仍在 [`.scratch/review-report/`](../../../.scratch/review-report/README.md)，验收矩阵见 [Spec](../../../.scratch/review-report/spec.md)。Spec 和对应工单引用本档案，避免历史证据与需求脱节。
